The funniest one-line pickup line a robot could use, 200 characters or fewer.

> I ran a million simulations of us meeting. In every single one, you said yes — so this is just a formality.

`main.ts` writes the line to `/output/entry.txt` and asserts the gate (1–200 characters, one line, not only white space).
